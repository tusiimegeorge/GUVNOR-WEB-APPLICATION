HOW TO USE
================================================================================

1. VIEW THE COMPONENT
   - Homepage: https://your-site.com/dashboard
   - Look for "Upcoming Events" section with calendar

2. INTERACT WITH CAROUSEL
   - Click up arrow to go to previous event
   - Click down arrow to go to next event
   - Watch calendar update automatically
   - See counter showing position (e.g., "2 of 5")

3. INTERACT WITH CALENDAR
   - Click any date highlighted in magenta
   - See event count in footer
   - Date gets selected and highlighted
   - (Future: can add event detail view)

4. VERIFY DATA
   - Check Supabase events table has data
   - Confirm event_status is "upcoming" or "happening_now"
   - Verify event_date format (YYYY-MM-DD)
   - Browse by carousel and calendar
